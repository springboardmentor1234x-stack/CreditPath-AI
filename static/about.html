Project Overview

This web application is the frontend for a full-stack loan default prediction model, built as part of an internship project.

Core Components:

  • Machine Learning Model: A tuned XGBoost classifier trained on the (Anonymize_Loan_Default_data.csv) dataset to predict the probability of default.
  • Backend API: A FastAPI (Python) server that serves the model, handles feature engineering, and provides a "Decision Engine" to map risk scores to actions (Approve, Deny, Review).
  • Frontend App: This (HTML, CSS, JS) website, which allows users to submit batch applications and view the model's recommendations in real-time.

Key Project Steps:

  1. Data cleaning and exploration.
  2. Fixing data leakage.
  3. Advanced feature engineering (creating features like 'risk_weighted_debt_load').
  4. Comparing imbalance techniques (SMOTE vs. scale_pos_weight).
  5. Model tuning and validation (achieving a 0.71 AUC).
  6. Deploying the model with a FastAPI backend.
  7. Building this multi-page frontend.
